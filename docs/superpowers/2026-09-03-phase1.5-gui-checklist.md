# Phase 1.5 manual GUI checklist (run: mise exec -- yarn tauri dev)
1. Sidebar: floating rounded panel with icons; 설정 section shows 일반/모델/번역/오버레이; collapse leaves icons only; footer shows the current ASR model name.
2. Settings > 모델: 전사/번역 segments; rows show 용량 · 설명 · speed dots; "추천" on Small / Qwen 3.5 2B.
3. Download Whisper Tiny (75 MB): row shows "다운로드 중 · N% · x MB / 75 MB" and a green bar; other rows' 다운로드 buttons are disabled meanwhile; on completion the row shows "설치됨" + 선택 + 삭제.
4. Cancel mid-download (Whisper Base): row returns to 다운로드; start again → progress resumes from the previous received bytes (watch the first percentage).
5. Select the installed model: it gets "사용 중" (green), no button; the previous model shows 설치됨 + 선택 + 삭제 immediately (no stale badge). Delete a non-in-use installed model → row returns to 다운로드.
6. Error surface: with a download running, quickly click 다운로드 on another row before the first progress tick → localized "다른 모델을 내려받는 중입니다" (never a raw "busy").
7. Settings > 오버레이: no monitor thumbnails; preview card reflects display mode / font size / opacity live; 위치 조정 → drag overlay to another monitor (if any) → 조정 완료 → relaunch restores on that monitor.
8. Live: header line "AUTO → 시스템 기본 · Whisper Small · Qwen 3.5 2B"; no empty-state text or shortcut hint anywhere.
9. Onboarding (delete settings.json first): progress bar stepper; titles only; ASR step footer reads "75 MB 받고 계속" for Tiny → downloads → auto-advances to the LLM step when installed. Cancel a footer-started download from the row → the footer button re-enables. Select a different row while a download runs → no auto-advance for the other model.
10. macOS: model files land under ~/Library/Application Support/com.babelay.app/models/{asr,llm}/ (local data dir).
