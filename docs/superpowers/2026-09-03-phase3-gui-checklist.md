# 3단계(번역) GUI 확인 체크리스트 — 2026-09-03

`mise exec -- yarn tauri dev` 로 실행하되, 시스템 오디오 권한은 실행한 터미널에 귀속된다(README 참고).
음성은 `say -r 170 "The quick brown fox jumps over the lazy dog."` 같은 명령으로 낸다.

- [ ] **로컬 번역 한 세트** — 설정 › 번역: 로컬 모델(Qwen 3.5 2B 설치), 원어 `auto`, 타겟 `한국어`. 라이브 시작 → 영어 문장을 재생하면 오버레이에 번역(크게)+원문(작게)이 **동시에** 바뀐다. 번역이 늦으면 직전 세트가 최대 3초 유지되고, 그 뒤엔 원문만 뜬다.
- [ ] **표시 모드 3종** — 오버레이 탭에서 `원문 + 번역` / `원문만` / `번역만` 을 바꾸면 다음 세션부터 반영된다. `원문만` 이면 번역 모델이 없어도 시작된다.
- [ ] **원어 == 타겟** — 타겟을 `영어` 로 두고 영어를 재생하면 번역 줄이 없고 오류 배너도 없다.
- [ ] **클라우드 키 저장** — 클라우드 API › 프로바이더 선택 → API 키 입력 → 저장 → `저장됨 ●●●●` 배지. 앱을 재시작해도 배지가 남는다(키체인). 설정 파일(`settings.json`)에는 키가 없다.
- [ ] **연결 테스트** — `연결 테스트` 를 누르면 `NNN ms · <번역 문장>` 초록 배너가 5초 표시된다. 로컬 모델에서도 동작한다(첫 로드 포함 20초 안).
- [ ] **잘못된 키** — 키를 엉뚱한 값으로 저장하고 연결 테스트 → 빨간 배너 1회(`번역에 실패했습니다 · …`). 라이브 시작 후 실패해도 오류 배너는 30초에 한 번만 뜨고 원문 자막은 계속 나온다.
- [ ] **키 삭제** — `삭제` 를 누르면 입력 상자로 돌아오고, 라이브 시작 시 `API 키를 입력하세요` 로 막힌다. 프로바이더를 바꾸면 그 프로바이더의 키 상태를 따로 보여준다.
- [ ] **히스토리** — 세션 상세에서 각 조각 아래 번역이 굵게 보이고, 사이드바 검색에 번역 단어(예: `안녕`)를 넣어도 찾힌다.
- [ ] **내보내기** — SRT 는 블록마다 원문 줄 + 번역 줄, TXT 는 `원문<TAB>번역`.
- [ ] **GPU 토글 끔** — 모델 탭에서 가속을 끄고 라이브 시작 → 로컬 번역이 CPU 로도 나온다(느려도 세트 규칙은 같다). 캡처 중 바꾼 설정은 정지 후 다음 세션부터 적용된다.
