# 2단계 GUI 수동 체크리스트 (전사 엔진)

작성: 2026-09-03. 자동 테스트로는 못 잡는 항목만 손으로 확인한다. 기준은 macOS(Apple Silicon)이고, Windows 항목은 별도로 표시했다.

## 사전 조건

- 탭 실험으로 Core Audio 데몬이 엉켰다면 먼저 `sudo killall coreaudiod` 또는 재부팅. 이걸 건너뛰면 캡처 시작이 조용히 실패한다.
- 설정 > 모델에서 Whisper Tiny 또는 Small을 먼저 설치해 둔다. 모델이 없으면 아래 대부분이 진행되지 않는다.
- 확인할 소리를 미리 준비한다(사람 말소리가 들어간 영상·팟캐스트).

## 체크리스트

1. **권한 프롬프트(macOS)**: 권한을 아직 준 적 없는 상태에서 처음 캡처를 시작하면 시스템 오디오 녹음 TCC 프롬프트가 뜬다. 거부하면 오류 안내와 시스템 설정 딥링크 버튼이 보이고, 허용하고 다시 시작하면 캡처가 붙는다.
2. **캡처 시작/정지 3경로**: 라이브 페이지의 시작/정지 버튼, 트레이 메뉴, `⌘⇧S`(Windows `Ctrl+Shift+S`) 셋 다 같은 세션을 토글한다. 어느 경로로 시작하든 다른 경로로 정지된다.
3. **트레이 라벨**: 캡처 중이면 트레이 메뉴 항목이 "정지", 멈춰 있으면 "시작"으로 바뀐다. UI 언어를 바꾸면 라벨도 따라간다.
4. **Partial / Final**: 소리를 재생하고 캡처를 시작하면 약 2초 안에 Partial(흐린 줄)이 라이브 타임라인과 오버레이에 나타나고, 문장 끝 무음 뒤 Final로 확정된다. Final은 타임라인에 고정으로 쌓인다.
5. **오버레이 페이드**: 2단계 오버레이는 원문 줄만 보여준다(번역 줄 없음). 소리를 멈추면 약 6초 뒤 페이드아웃하고, 다시 말소리가 들어오면 되살아난다.
6. **CPU 폴백 배지**: 설정 > 모델 하단의 GPU 가속 토글을 끄고 캡처를 다시 시작하면 라이브 페이지에 "CPU" 칩이 뜬다. 토글을 켜고 재시작하면 칩이 사라진다.
7. **지연 칩**: 큰 모델(Large v3 Turbo)을 CPU로 돌리는 등 일부러 부하를 주면 "지연" 칩이 뜨고, 부하가 풀리면 사라진다. 이때도 Final 조각은 하나도 빠지지 않는다.
8. **히스토리 저장·상세**: 캡처를 정지하면 히스토리 목록 맨 위에 방금 세션 행이 생긴다. 행을 열면 조각이 시간순으로 보이고 개수가 라이브에서 본 것과 맞는다.
9. **히스토리 검색·내보내기·삭제**: 조각에 실제로 나온 단어로 검색하면 해당 세션·조각이 걸린다. TXT와 SRT를 각각 내보내면 저장 경로를 알려주는 토스트가 뜨고 파일이 실제로 그 경로에 있다. 세션 삭제 후 목록과 검색 결과에서 함께 사라진다.
10. **사양 한 줄과 balanced 배지**: 설정 > 모델 상단의 사양 한 줄(칩 · 메모리 · GPU)이 실제 머신과 맞고, "추천" 배지가 사양 표를 따른다. M2 Pro 16 GB → 전사 Large v3 Turbo, 번역 Qwen 3.5 4B.
11. **모델 로딩 중 정지**: 큰 모델로 캡처를 시작해 로딩이 끝나기 전에 정지를 누른다. 앱이 멈추지 않고 정상 종료되며, 히스토리에 빈 세션이 둘 생기지 않는다(중복 세션 없음).
12. **캡처 중 종료**: 캡처가 도는 상태에서 앱을 종료한다. 남은 조각을 흘려보낸 뒤 프로세스가 실제로 빠지고(좀비 없음), 히스토리의 그 세션에 `ended_at`이 채워져 있다.

## Windows 보류

Windows 캡처는 캡처 모듈만 크로스 타깃 `cargo check`로 확인했다(워크스페이스 전체 check는 `ring`이 막는다). 위 1번을 뺀 나머지는 CUDA 툴킷이 설치된 Windows 머신에서 다시 한 번 돌려야 한다.
