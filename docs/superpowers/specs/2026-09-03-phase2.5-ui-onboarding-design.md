# Babelay 2.5단계: UI 리디자인(daisyUI) + 백그라운드 온보딩 + 오버레이 수정 설계

작성일: 2026-09-03
상태: 구현 완료(2026-09-03)
상위 스펙: `docs/superpowers/specs/2026-09-02-babelay-design.md` (이 문서가 §7과 충돌하면 이 문서가 우선)
목업: `.superpowers/brainstorm/11316-1788414938/content/` (layout A, onboarding-v4, overlay; gitignore 대상이라 커밋되지 않음)

## 1. 목표

1. 메인 창을 Meetily 구조(고정 사이드바 + 하단 액션, 설정 탭)로 바꾸되 색·형태는 `docs/design/spotify-design.md` 토큰을 유지한다.
2. 스타일링을 daisyUI 5로 옮겨 직접 만든 컴포넌트를 줄인다.
3. 창 폭에 반응한다(사이드바 자동 접힘, 유동 폭, 미리보기 비율 유지).
4. 온보딩에서 모델 다운로드를 백그라운드로 돌리고 진행률은 오른쪽 상단 토스트로 보여준다. "시작하기"는 Transcript 모델이 설치될 때까지 비활성.
5. 권한 단계와 설정 › 일반에 필요한 권한 이름을 보여주고, 허용되면 체크 아이콘.
6. 사용 중 모델도 삭제할 수 있게 한다.
7. 오버레이: 표시 모드 반영, 조정 모드에서 예시 문구 표시, 모서리 드래그로 폭 조절(macOS 포함), 미리보기 반응형.
8. 문구: "전사"를 "Transcript"로 통일. 번역 탭에 타겟 언어 설정.

## 3. 스타일링 기반

### 3.1 daisyUI 도입

`package.json`에 `daisyui` 추가. `src/index.css`:

```css
@import "tailwindcss";
@plugin "daisyui" { themes: false; }
@plugin "daisyui/theme" { name: "babelay"; default: true; color-scheme: dark;
  --color-base-100: #121212; --color-base-200: #181818; --color-base-300: #1f1f1f;
  --color-base-content: #ffffff; --color-neutral: #252525; --color-neutral-content: #ffffff;
  --color-primary: #1ed760; --color-primary-content: #000000;
  --color-error: #f3727f; --color-error-content: #000000;
  --radius-box: 12px; --radius-field: 9999px; --radius-selector: 9999px; }
@plugin "daisyui/theme" { name: "babelay-light"; color-scheme: light;
  --color-base-100: #ffffff; --color-base-200: #f5f5f5; --color-base-300: #eeeeee;
  --color-base-content: #121212; --color-neutral: #e4e4e4; --color-neutral-content: #121212;
  --color-primary: #1ed760; --color-primary-content: #000000;
  --color-error: #d33a4a; --color-error-content: #ffffff;
  --radius-box: 12px; --radius-field: 9999px; --radius-selector: 9999px; }
```

보조 텍스트 색(`#8a8a8a`/`#6a6a6a`)은 `--color-fg-muted` 커스텀 변수로 두고 `text-fg-muted` 유틸리티를 유지한다. 초록은 "채우기 + 검정 글자"로만 쓴다(daisyUI `btn-primary`가 그 규칙과 같다).

### 3.2 테마 적용

`src/lib/theme.ts`의 `applyTheme`가 `html.dark` 클래스 대신 `document.documentElement.dataset.theme = "babelay" | "babelay-light"`를 쓴다. system은 `prefers-color-scheme` 리스너로 둘 중 하나를 고른다. 기존 `theme.test.ts`·`theme-dom.test.ts`는 속성 검사로 바꾼다.

### 3.3 컴포넌트 정리

| 삭제 | 대체 |
|---|---|
| `PillButton` | `btn btn-primary/btn-ghost/btn-outline btn-sm` |

| `Badge` | `badge badge-primary/badge-neutral badge-sm` |
| `ProgressBar` | `progress progress-primary` |

유지: `Sidebar`(교체), `ModelRow`(수정), `SegmentedControl`(daisyUI `join`을 감싸는 12줄 래퍼로 재작성 — 네 곳의 중복을 막는다), `SettingGroup/SettingRow`(얇게), `ErrorBar`(`alert alert-error`), `icons.tsx`.

## 4. 메인 창

### 4.1 사이드바

`Sidebar.tsx` 교체. 고정 폭 208px, `bg-base-200`, 오른쪽 1px 구분선(`border-base-300`). 떠 있는 패널·그림자는 버린다.

- 상단: 앱명(초록 사각 아이콘 + "Babelay"), 히스토리 검색 인풋(`input input-sm rounded-full`). 입력 후 Enter → `/history?q=…`로 이동. History 페이지는 쿼리 파라미터를 초기 검색어로 쓴다.
- 메뉴: 라이브, 히스토리 (`NavLink`, 활성은 `bg-neutral font-semibold`).
- 하단(`mt-auto`): `시작`/`정지` 버튼(`btn btn-primary btn-block`, 캡처 중이면 `정지`, 정지 중이면 disabled + "정지 중…"), `설정`(`/settings/general`), `정보`(모달), 버전 텍스트(`text-xs text-fg-muted`, 값은 `import.meta.env.PACKAGE_VERSION`을 vite `define`으로 주입).
- 시작 버튼은 설치된 Transcript 모델이 없으면 disabled. 툴팁(`tooltip`)에 `errors.modelMissing`.
- 접기: 폭 800px 미만이면 CSS 미디어 쿼리로 아이콘만(56px). 수동 토글 버튼은 사이드바 오른쪽 가장자리 원형(`btn btn-circle btn-xs`)으로 유지하고 localStorage 키 `babelay.sidebar`는 그대로. 수동 접힘은 넓은 창에서도 적용된다.
- 정보 모달: 앱명, 버전, `get_hw_info` 결과 한 줄, 닫기.

라이브 페이지 헤더에서 시작/정지 버튼을 뺀다(사이드바로 이동). 오버레이 켬/끔은 `join` 두 개 버튼으로 남긴다.

### 4.2 라우트

```
/live, /history, /settings/:tab (general|models|translation|overlay), *
```

`/settings`는 `/settings/general`로, 옛 `/settings/transcription`은 `/settings/models`로 리다이렉트.

### 4.3 설정 페이지

`pages/Settings.tsx` 신규: 제목 "설정" + `tabs tabs-border`(아이콘 + 라벨 4개, 활성 탭은 `NavLink`) + 아래에 탭 내용. 기존 4개 페이지 파일은 탭 내용 컴포넌트로 남는다(제목 `<h2>` 제거).

**일반**
- 그룹 1: 테마(select), 언어(select; "시스템 기본" 옵션 라벨은 `시스템 기본 (한국어)`처럼 `navigator.language`로 해석한 언어명을 괄호로 붙인다).
- 그룹 2: 권한 — `PermissionRow`(§5.2). Windows에서는 그룹 자체를 숨긴다.
- 그룹 3 대신 제목 오른쪽에 `?` 아이콘 버튼(`tooltip tooltip-left`)에 단축키 두 줄. 별도 그룹 없음.

**모델**
- 하드웨어 한 줄, 세그먼트 `Transcript` / `번역`, `ModelRow` 목록, GPU 토글. 기존과 동일하되 삭제 규칙은 §6.

**번역**
- 세그먼트 로컬/클라우드 + 기존 그룹.
- 그룹 추가: `원어`(select: 자동 감지/한국어/영어/일본어 → `asr.source_lang`), `타겟 언어`(select: 시스템 기본/한국어/영어/일본어 → `overlay.subtitle_lang`). 오버레이 탭에서 두 행을 뺀다.

**오버레이**
- 헤더: "미리보기" 라벨 + `위치 조정`/`조정 완료` 버튼.
- 미리보기 카드: `aspect-[16/7] @container` (Tailwind 4 컨테이너 쿼리). 자막 상자는 카드 폭 60%, 글자는 `cqw` 단위(원문 `2.6cqw`, 번역 `4.2cqw`)에 `font_size / 28` 배율을 곱한다. 표시 모드 규칙은 `overlayLines()`(§7.1)를 공유한다.
- 그룹: 표시 모드(join), 글자 크기(range 14–64), 배경 투명도(range 0–100).

### 4.4 반응형 규칙

- 사이드바: ≥800px 펼침, <800px 아이콘. 메인 창 최소 크기는 720×480 유지.
- 콘텐츠 최대 폭 `max-w-3xl`, 좁으면 폭 100%.
- `ModelRow`: `grid-cols-[1fr_auto]` 유지, 이름·메타는 `min-w-0 truncate`. 버튼 그룹은 `flex-wrap`.
- `SettingRow`: 컨트롤이 넘치면 `flex-wrap`으로 라벨 아래로 내려간다.
- 온보딩 창: `resizable(true)`, `min_inner_size(640, 480)`. 본문은 `max-w-2xl mx-auto w-full`.

## 5. 온보딩

### 5.1 흐름

단계: 언어 → 권한(macOS만) → Transcript 모델 → 번역 모델 → 완료. 상단은 daisyUI `steps`(완료 단계는 `step-primary`, 원 안에 ✓, 현재는 번호).

- 모델 단계의 주 버튼은 항상 `다음`. 고른 모델이 미설치면 `다음` 클릭 시 `useModels.enqueue(id)`를 호출하고 바로 다음 단계로 간다. 이미 설치면 그냥 이동.
- 번역 단계는 `건너뛰기` 유지.
- 완료 단계: 체크리스트 그룹 3행 — `Transcript 모델 · {이름}`, `번역 모델 · {이름 | 건너뜀}`, `시스템 오디오 녹음`(macOS만). 각 행 오른쪽은 ✓ / 진행률 % / ✕.
- `시작하기`는 `models.find(asr 선택).installed`일 때만 활성. 활성 조건에 번역 모델은 없다.
- `이전`으로 돌아가 다른 모델을 고르면 큐를 갈아끼운다(`enqueue`가 같은 kind의 대기 항목을 교체). 이미 받는 중인 파일은 취소하지 않는다(설치되면 그대로 남고 삭제는 모델 탭에서).

### 5.2 권한 표시

`PermissionRow` 컴포넌트(온보딩 권한 단계와 설정 › 일반 공용):

```
[시스템 오디오 녹음                       ] [✓ | ✕ | ?]
[macOS · 개인정보 보호 및 보안 › 시스템 오디오 녹음]
```

- 상태: `granted` → 초록 원 ✓, `denied` → 빨강 원 ✕, `unknown`/null → 회색 원 `?`.
- 아래 버튼: `권한 확인`(`check_audio_permission`), `시스템 설정 열기`(`open_privacy_settings`; denied면 primary).
- 상태 조회는 온보딩 권한 단계 진입 시 한 번, 설정 › 일반은 탭 진입 시 한 번(둘 다 실제 탭 생성이므로 자동 반복 호출 금지).
- Windows: 온보딩에서 단계 제거(기존과 동일), 설정에서 그룹 숨김.

### 5.3 다운로드 토스트와 큐

`useModels` 확장:

```ts
queue: string[];                 // 대기 중 모델 id (받는 중인 것은 models[].download가 진실)
enqueue(id): Promise<void>;      // 받는 중이 없으면 download(id), 있으면 큐에 push (같은 kind는 교체)
dequeue(id): void;
```

`bind()`의 `model-download` 리스너가 `done|error|cancelled`를 받으면 `refresh()` 후 큐 앞을 꺼내 `download()`한다. 백엔드 동시 1개 제한은 그대로다.

`DownloadToast`(`toast toast-top toast-end`): 받는 중인 모델마다(실제로는 최대 1) 카드 한 장 — 이름, `%` · 받은/전체, `progress`, 취소 ✕. 큐에 대기 항목이 있으면 아래 줄에 `다음: {이름}`. 받는 중·대기 모두 없으면 렌더하지 않는다. `MainApp`과 `Onboarding` 루트에 한 번씩 놓는다. 실패는 기존 `ErrorBar` 경로 그대로.

## 6. 모델 삭제

- 프론트: `rowAction`이 `in_use`일 때 `delete`를 돌려주고, `ModelRow`는 이 경우 `삭제` 버튼(휴지통 아이콘 + 라벨, `btn-ghost btn-sm`)만 보여준다. 설치됨·미사용은 기존대로 `선택`+`삭제`.
- 삭제 클릭 → `ConfirmModal`("{이름}을(를) 삭제할까요? {용량}") → 확인 시 `remove(id)`.
- 백엔드 `models::delete`: `in_use` 거부를 없앤다. 대신 삭제 후 설정에서 `asr.model_id` 또는 `translation.local_model`이 그 id면 빈 문자열로 바꿔 저장한다. 캡처 중(`session::is_capturing`)이면 `capturing` 코드로 거부한다(파일을 읽는 중이므로). 프론트 `ERROR_KEYS`에 `capturing → errors.capturing`.
- 빈 `asr.model_id`는 `start`가 이미 `model_missing`으로 거부한다. 사이드바 시작 버튼 disabled 조건(§4.1)이 그 전에 막는다.
- `errors.inUse` 키는 삭제한다(세 로케일 모두).

## 7. 오버레이 창

### 7.1 표시 모드

순수 함수 `overlayLines(mode, final, partial, translated?)` → `{ primary?: string; secondary?: string }`:

- `both`: translated가 있으면 primary = 번역, secondary = 원문(한 세트). 없으면 primary = final 원문, secondary = partial(흐리게).
- `source`: primary = final 원문, secondary = partial(흐리게).
- `target`: primary = 번역, secondary 없음. 번역이 없으면(대기 만료·실패) primary = 원문으로 내려간다 — 빈 상자를 띄우지 않는다.

`OverlayWindow`와 설정 미리보기가 같은 함수를 쓴다. 미리보기는 final 자리에 `overlay.previewSource`, translated 자리에 `overlay.previewTarget`을 넣는다.

### 7.2 조정 모드

- 조정 모드에서는 `overlayLines`에 예시 문구(`overlay.previewSource`/`previewTarget`)를 넣어 항상 글자가 보인다. 캡처 중이면 실제 자막을 우선한다.
- 자막 상자는 조정 모드에서 `w-full`(창 폭을 꽉 채움), 평소에는 `max-w-full`.
- 리사이즈 핸들: `startResizeDragging` 대신 포인터 이벤트로 구현한다. `pointerdown`에서 `setPointerCapture`, 시작 시점의 `inner_size`와 스크린 좌표를 기억하고, `pointermove`마다 `requestAnimationFrame`으로 묶어 `getCurrentWindow().setSize(new PhysicalSize(round(w0 + dx * devicePixelRatio), h0))`를 호출한다. 폭 하한은 240px(물리). `pointerup`에서 `overlayCommitPosition()`. 창 `onResized`의 디바운스 커밋은 그대로 두어 두 경로가 같은 값을 쓰게 한다.
- 이동은 지금처럼 `startDragging`(macOS에서 동작한다).
- 배지 문구 `overlay.adjustHint`는 "드래그로 이동 · 모서리로 폭 조절"로 바꾼다.
