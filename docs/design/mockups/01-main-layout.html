C. 라이브 단일 화면 + 설정/히스토리는 모달

메인 창은 항상 라이브 로그. 설정과 히스토리는 위에 뜨는 모달. 가장 단순하지만 설정 항목이 많아지면 모달이 답답해짐.

제 추천은 A입니다. 설정 항목(모델·번역·오버레이·GPU)이 많아 사이드바 하위 항목으로 펼치기 좋고, 캡처 상태를 항상 볼 수 있습니다.
