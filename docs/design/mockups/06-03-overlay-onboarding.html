문구 정리 목록

  • 라이브: 빈 상태 안내 문장·단축키 힌트 삭제. 헤더에 "EN → KO · 모델명" 한 줄만.
  • 설정 > 일반: 단축키 카드 유지(값만), 설명 없음.
  • 오버레이 미리보기: 설정 페이지 안에 실제 스타일을 미리보는 카드 추가. 조정 모드 힌트 칩은 오버레이 위에서만.
  • 온보딩: "권한이 필요합니다" 설명 → 제목 + 버튼 2개만. "추천 모델에 배지를 표시했습니다" 문장 삭제. 완료 화면은 "준비 완료" + 시작하기.
  • 모델 행: 속도는 점 5개, 설명은 한 구절.
  • 트레이: 그대로.
