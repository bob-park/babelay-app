앱 아이콘 — 어떤 컨셉으로 갈까요?

오버레이 위치는 B(드래그 자유 배치)로 확정했습니다. 아이콘은 macOS 스쿼클 마스크 기준이며, 근흑 배경 + 초록 액센트 규칙을 그대로 따릅니다. 각 시안 옆의 작은 것은 메뉴바/트레이용 단색 아이콘입니다.

128 px
트레이 (라이트/다크)

A. 자막 말풍선

말풍선 안에 두 줄(원문 회색 · 번역 초록). "원문+번역 자막"이라는 기능이 한눈에 읽힘. 작은 크기에서도 형태가 살아남음.

128 px
트레이 (라이트/다크)

B. 파형 → 텍스트

왼쪽 초록 파형이 오른쪽 텍스트 줄로 이어짐. "소리를 글자로"라는 동작을 직접 표현. 요소가 둘이라 16px에서는 다소 빽빽함.

128 px
트레이 (라이트/다크)

C. 바벨탑 (층층이 쌓인 자막 줄)

이름 Babelay에서 따온 바벨탑을 자막 줄 4개로 추상화. 가장 단순하고 브랜드 성격이 강함. 기능이 바로 읽히진 않지만 기억에 남음.

제 추천은 C입니다. 형태가 단순해 16px 트레이부터 1024px까지 깨지지 않고, 이름과 연결되는 이야기가 있습니다. 실제 파일은 SVG 원본 하나에서 Tauri 아이콘 생성 명령으로 .icns / .ico / png 세트를 뽑습니다.
