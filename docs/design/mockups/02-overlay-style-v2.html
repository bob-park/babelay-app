사이드바는 접기/펼치기 가능한 A로 확정했습니다. 다음은 화면 위에 뜨는 자막 창의 기본 스타일입니다. 폰트 크기·투명도·색상은 설정에서 조절 가능하고, 여기서 정하는 것은 출시 시 기본값입니다.

A. 반투명 바 · 원문 + 번역 2줄

어두운 반투명 배경 위에 원문(작게, 회색)과 번역(크게, 흰색). 배경 덕에 어떤 화면 위에서도 읽힘. 원문 표시는 끌 수 있음.

B. 외곽선 텍스트 · 번역만

배경 없이 검은 외곽선 텍스트. 영화 자막 느낌으로 화면을 가장 덜 가림. 밝은 화면에서는 가독성이 A보다 낮음.

C. 필 캡슐 · 줄마다 배경

디자인 시스템의 필 형태를 그대로 가져온 스타일. 줄 길이에 맞춰 배경이 붙어 여백이 적음. 짧은 문장에 예쁘고 긴 문장은 줄바꿈이 어색할 수 있음.

제 추천은 A입니다. 회의·강의처럼 밝은 화면이 많은 용도에서 가독성이 가장 안정적이고, 원문을 함께 보여줘 오역을 바로 알아챌 수 있습니다. B, C는 설정의 "스타일 프리셋"으로 추가하면 됩니다.
